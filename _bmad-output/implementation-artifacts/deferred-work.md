## Deferred from: code review of story-1.9 (2026-05-25)

- **Watcher anchor hang risk on writer panic + mtime-resolution flake on coarse filesystems** [`crates/orgsidian-watcher/tests/anchor.rs`] [MED] — The anchor relies on a `FakeClock` that never advances; if the writer thread's `std::fs::write().expect(...)` panics (disk full, EPERM, signal) the detector's mtime poll loop never observes a change AND the FakeClock-driven deadline never fires → `cargo test` hangs indefinitely (no stable `#[test]` timeout in Cargo). Same hang on coarse-resolution filesystems (HFS+ 1s, FAT 2s, some NFS) where the 50ms writer delay can't disambiguate from `initial_mtime`. Dev Notes §9 anticipates the resolution path. Owner: Story 5.1 (notify-rs replaces the polling body and the FakeClock-driven hang surface entirely).
- **`metadata().modified()` race vs. `renameat` from `atomic-write-file` in the polling detector** [`crates/orgsidian-watcher/src/lib.rs:60`] [LOW] — `std::fs::metadata(path)?` between the initial reading and a concurrent `atomic-write-file::commit()` (which does `renameat`) can race and return `ENOENT` → `DetectError::Io(NotFound)` instead of `Ok(DetectedEvent)`. Anchor uses `std::fs::write` (truncate-in-place, not rename) so latent. Owner: Story 5.1 (notify-rs event subscription replaces the polling body and resolves the race in one stroke).
- **Temp-file leak on `write_all` error path in `atomic_write`** [`crates/orgsidian-vault/src/lib.rs:18-22`] [LOW] — If `AtomicWriteFile::open` succeeds but `write_all` fails, the temp-sibling-file cleanup depends on `AtomicWriteFile`'s `Drop` impl (not documented by the crate). On cross-device targets (tmpfs/bind-mount) `commit()` returns `EXDEV` and the temp may persist next to the target. Anchor's one-shot happy path doesn't exercise. Owner: Story 3.1 (AV-aware retry wrapper + production error-path semantics).
- **`atomic_write` returns bare `io::Error` for `EISDIR` / `ENOENT` (no context wrapping)** [`crates/orgsidian-vault/src/lib.rs:18`] [LOW] — Caller can't distinguish "target path invalid" from "transient I/O" without `ErrorKind` introspection. AC2 explicitly bounds Story 1.9 to a single delegation chain. Owner: Story 3.1 (production-grade error context wrapping per LD-8).
