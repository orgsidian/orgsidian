## Hacker News ("Show HN")

**Title:** `Show HN: Orgsidian – a desktop org-mode app that isn't Emacs (v0.1 Alpha, macOS/Linux)`

**Body:**

Org-mode is, in my opinion, the most powerful integrated planner-and-knowledge format that exists — plain text, one file format for tasks, dates, time tracking, and notes together. The catch is that it lives inside Emacs, and Emacs is a real barrier for a lot of people who'd otherwise want to use it.

Orgsidian is a cross-platform desktop app that opens, edits, and organizes `.org` files directly — no Emacs required — while staying byte-for-byte round-trip faithful to the format, so it plays well with Emacs or any other tool that already reads your files.

v0.1 Alpha, out today, covers a first-launch-to-first-week slice:

- Starter Vaults (Personal GTD / Student) that generate realistic content on first launch, so Today/Week views aren't empty
- Today and Week Agenda views (Scheduled + Deadline items, click straight through to the source file)
- An org-aware editor (CodeMirror-based, Raw / Pseudo-WYSIWYG / Split modes, TODO/tag/timestamp decorations, optional Emacs keybindings)
- Safe handling of external edits — edit the same file from Emacs (or `git`, `sed`, anything) without losing either version
- Dark + light themes with WCAG AA contrast
- A `tree-sitter-org`-backed parser validated against a real-world corpus and an Emacs ground-truth oracle

It's early — no capture, search, backlinks, graph view, or time-tracking dashboard yet (all on the roadmap for v0.5). This release is specifically about the daily-driver loop: install it, point it at a folder (or generate a Starter Vault), and see your day.

MIT licensed. Feedback, bug reports, and "why isn't this like Emacs org-mode does it" comments are all welcome on the repo's Issues.

## Reddit r/orgmode

**Title:** `Orgsidian v0.1 Alpha: a desktop org-mode app for people who don't (or don't want to) use Emacs`

**Body:**

Hi r/orgmode — sharing a project I've been building: **Orgsidian**, a cross-platform desktop app that reads, edits, and organizes `.org` files without requiring Emacs.

The goal isn't to replace Emacs for the people who are happy in it — it's to make org-mode's *format* usable by people who never will be. Orgsidian is local-first, open source (MIT), and treats round-trip fidelity to the plain-text format as non-negotiable: it writes your `.org` files back byte-for-byte, preserving exactly what was already there, so a Vault can be shared between Orgsidian and Emacs without either one mangling the other's output.

**What's in v0.1 Alpha** (available today for macOS and Linux):

- **Starter Vaults** — Personal GTD and Student presets that generate a realistic Inbox/Projects (or Courses)/Journal/Someday setup on first launch, so you see the workflow immediately instead of a blank editor
- **Today + Week Agenda** — Scheduled and Deadline items across the whole Vault, grouped and linked back to the source Headline
- **An org-aware editor** — CodeMirror 6 under the hood, with Raw / Pseudo-WYSIWYG / Split modes, TODO-state and tag decorations, clickable links, a Schedule/Deadline date picker, and an opt-in Emacs keybindings mode for anyone coming from `org-mode` muscle memory
- **External-edit safety** — the watcher knows when a file changed on disk from outside Orgsidian (e.g. from Emacs, `git checkout`, a sync client) and either reloads cleanly or blocks Save with a conflict warning, so it never silently clobbers changes
- **Dark + light themes**, WCAG AA contrast, instant toggle
- **A `tree-sitter-org`-backed parser** validated against a real-world `.org` corpus plus an Emacs `29.x`/`30.x` ground-truth oracle

**Not yet there:** capture, full-text search, backlinks, graph view, and time-tracking/clocking. Those (plus a full interactive merge dialog for conflicting edits, and Windows support) are the next milestones — full roadmap is in the [epics/stories doc](https://github.com/orgsidian/orgsidian/blob/main/_bmad-output/planning-artifacts/epics.md) if anyone's curious how a project like this gets planned out.
