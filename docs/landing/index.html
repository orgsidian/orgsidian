Orgsidian

The desktop planner-and-knowledge app that opens, edits, and organizes .org files — without requiring Emacs.

Download the latest release View on GitHub

What it is

Org-mode is one of the most powerful integrated planner-and-knowledge formats ever shipped, but it lives inside Emacs — and Emacs is a hard barrier for most people. Orgsidian is desktop-native, cross-platform, open source, and faithful to the plain-text format: it reads and writes .org files byte-for-byte round-trip faithfully, so it plays well with every other tool that already reads your files — Emacs included.

In v0.1 Alpha

  • Starter VaultsPersonal GTD and Student starters generate realistic Inbox/Project/Journal content on first launch.
  • Today + Week AgendaScheduled and Deadline items across your whole Vault, one click back to the source Headline.
  • Org-aware editorCodeMirror-based Raw / Pseudo-WYSIWYG / Split modes, TODO/tag/timestamp decorations, optional Emacs keybindings.
  • External-edit safetyEdit the same file from Emacs or any other tool without losing either version.
  • Dark + light themesWCAG AA-contrast themes with an instant Settings toggle.
  • Round-trip-faithful parserA tree-sitter-org-backed parser validated against a real-world corpus and an Emacs ground-truth oracle.

Not yet in v0.1: time-tracking, capture, full-text search, backlinks, graph view, and the interactive Merge Dialog — see the Roadmap for what's next.
